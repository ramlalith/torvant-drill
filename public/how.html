How it works

Gemini builds the drill ahead of time. Code runs the play. A person decides. Nothing is ever run.

Who does what

  • Gemini builds the drill queues and writes the card text. It never decides and never runs anything.
  • Rules set the lowest level. Gemini can raise it, never lower it. Code scores each round.
  • A person approves or denies.
  • Nothing is ever run. No source file can start a command, and a unit test checks this.

Honest limits

  • A 60 second game does not prove approval fatigue. It shows the measuring method.
  • Results are a small sample.
  • The risk rules are patterns. They catch known kinds of risk, not every trick.
  • Rules are patterns and they miss things. In Queue Q2 the rules did not flag a public deploy. Gemini raised it. That is why there are two layers.
  • We fix the card, not the person.
